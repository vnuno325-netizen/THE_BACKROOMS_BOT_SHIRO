# 👻 THE_BACKROOMS_BOT_SHIRO

Bot Discord con comando `/link` para enviar enlaces privados.

## 🚀 Despliegue en Railway

1. Ir a [railway.app](https://railway.app)
2. "Start New Project" → "Deploy from GitHub"
3. Seleccionar este repo
4. Agregar variable: `DISCORD_TOKEN=tu_token`
5. Listo ✅

## 🎮 Comandos

- `/link` - Envía link solo visible para ti

## 📝 Desarrollo Local

```bash
npm install
npm start
```
